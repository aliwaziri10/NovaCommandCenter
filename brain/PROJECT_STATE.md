Confirmed via Render dashboard screenshot this session: status **Live**, latest deploy `b58218a` succeeded. An earlier automated pipeline-status issue (#129, 2026-09-02 20:15 UTC) reported the backend as unreachable — almost certainly Render free-tier's documented idle spin-down (dashboard's own banner: "free instance will spin down with inactivity, can delay requests by 50 seconds or more"), not a real crash. - **Media storage migrated OFF Supabase Storage entirely, onto Backblaze B2** (bucket `nova-media-zia`, private, presigned URLs, 6-day expiry) — confirmed via README.md, dated 2026-09-02. Reason: Supabase Free's **50MB global file-size limit cannot be raised past 50MB by any bucket setting**, and Nova's CRF20 1080p renders are 600-750MB. **Do not re-enable or reference Supabase Storage for file uploads going forward** — confirmed dead end, not a live option on free tier.
- **New pipeline stage added 2026-09-03: `cinematographer_agent.py`**, sitting between `video_planning` and `video_clips` (`generate_videos.py`). Enriches each shot with a DP-style cinematography brief (framing, lens, etc.) before clip generation. New `videos.cinematography_done` column added same session; `video_clips` stage now gates on it as a safety net. Deployed live (`c01d9b1`, `b58218a`) — not yet observed processing a real video end-to-end.
- **YouTube description bug fixed 2026-09-03** (commit `a4faad67`, `.github/scripts/youtube_upload.py`): every prior upload used a generic hardcoded fallback description — the backend's `video.description` field is never populated anywhere in the pipeline, so `_build_final_description()` always fell through to the same templated text on every video, unlike Marius which builds a real per-video description from narration text. Fixed by porting Marius's `build_description()` pattern (sentence-boundary truncation of `script_content`, ~1500 chars) as the new primary source; generic fallback is now a genuine last resort only. Confirmed by Zia comparing Nova vs Marius YouTube Studio side by side. **Not yet verified on a real post-fix upload** — next video published should be checked for a real per-video description.
- **Constraint Gate gap fixed 2026-09-03** (issue #143): `constraint_gate.yml` defined `protected_files`/`required_if_protected_file_touched` in `constraints.json` but the gate script never actually checked them — only `banned_if_added` was enforced. A push stripping black-and-white/monochrome language from a protected file would have passed silently. Patch applied directly via GitHub web editor (Claude's GitHub connector lacks the `workflows` write scope needed for `.github/workflows/*.yml` — confirmed 403 on direct write attempt, same as historical Claude-connector limitation). Verified live post-edit: file content matches the fix exactly.
